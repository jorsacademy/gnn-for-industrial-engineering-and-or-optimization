# Examples

This directory contains solver-in-the-loop or script-oriented examples.

- `03_pyscipopt_learned_branching.py` — strong-branching imitation learning with a variable-constraint bipartite GNN and a custom PySCIPOpt `Branchrule`.
- `03_pyscipopt_learned_branching.md` — explanation, assumptions, and benchmark cautions.
- `05_directed_gnn_network_flow.py` — pointer to the full directed-flow notebook.

For the complete learning sequence, see `../APPLICATIONS.md`.
